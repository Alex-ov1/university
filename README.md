# University — L2 Informatique

Dépôt regroupant mes travaux pratiques et exercices réalisés en **L2 Informatique — option renforcée recherche, Université de Lille**.

## Contenu

### `depot_alr`

Travaux d'**Automates et langages réguliers**.

* Automates déterministes en Python
* Manipulation et représentation d'automates
* Exercices sur différents langages
* Fichiers JSON contenant des automates

### `depot_cbd`

Travaux de **Conception de Bases de Données**.

* TP et exercices de bases de données
* Exercices en langage UML et SQL

### `depot_poo_java`

Travaux de **Programmation Orientée Objet en Java**.

* Classes et objets
* Encapsulation et relations entre classes
* Héritage et Polymorphisme

## Organisation

Chaque dossier correspond à une matière ou à un ensemble de TPs :

```text
university/
├── depot_alr/       # Automates et langages réguliers
├── depot_cbd/       # Conception de bases de données
├── depot_poo_java/  # Programmation orientée objet en Java
└── README.md
```
